# PlaceHolder – szkic strony

Statyczna strona: Bootstrap 5.3, GSAP + ScrollTrigger, Lenis (wszystko z CDN). Bez builda.

- `index.html` – treść i sekcje
- `assets/css/style.css` – wygląd (kolory i fonty na górze pliku, w `:root`)
- `assets/js/main.js` – wideo na hover, animacje, formularz
- `assets/js/portfolio-data.js` – lista realizacji; nowe wesele = nowy obiekt w tablicy
- `MEDIA.md` – jakie pliki wideo/zdjęć przygotować i jak je wyeksportować

Podgląd: otwórz `index.html` w przeglądarce albo (lepiej) przez Live Server w VS Code.
Formularz ma `action="#"` – podepnij skrypt PHP na OVH albo Formspree.
